Setup (10 min)
1. Create a new GitHub repo, upload all these files (keep the .github folder).
2. Repo Settings > Secrets and variables > Actions > New secret: ANTHROPIC_API_KEY (from console.anthropic.com).
3. Settings > Pages > Deploy from branch > main / root. Your dashboard is at https://<user>.github.io/<repo>/
4. Actions tab > fetch-jobs > Run workflow once to test. After that it runs daily at 7 AM IST.
5. Edit sources.json to add PSU / job pages.
Cost: ~25 pages/day max with Haiku, roughly a few rupees a day.
